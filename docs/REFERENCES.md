# 📚 GameGear References

## Purpose

This document stores all design inspiration, development resources, UI references, and project decisions for GameGear.

## Brand Name

GameGear

## Brand Personality

* Premium
* Modern
* Luxury
* Gaming
* Minimal
* Powerful
* Professional

The website should feel like a premium gaming hardware brand instead of a generic e-commerce template.

# Visual Direction

The UI should communicate:

* Confidence
* High Performance
* Premium Hardware
* Professional Craftsmanship
* Modern Technology

Less is more.

# Icon Library

Lucide React

Use a single icon library throughout the project.

Avoid mixing icon packs.

---

# Images

Use:

* High-quality PNG or WebP images
* Transparent product images where possible
* Consistent image dimensions
* Optimized assets

Avoid watermarked or low-resolution images.

---

# Animations

* Fade In
* Slide Up
* Hover Lift
* Image Zoom
* Button Hover
* Page Transition

Animations should be subtle and purposeful.

---

# Layout Principles

Always prioritize:

* White space
* Readability
* Consistent spacing
* Visual hierarchy
* Alignment
* Responsive layouts

Every section should have a clear purpose.

---

# Component Philosophy

Before creating a new component, ask:

* Can an existing component be reused?
* Does this component have only one responsibility?
* Will this component be useful elsewhere?

Prefer reusable components over duplicated code.

# Commit Convention

Use Conventional Commits.

Examples

```text

feat: create reusable product card

style: improve responsive layout

refactor: simplify product grid

docs: update roadmap

chore: initialize project
```

# Development Principles

Every milestone should:

* Build one feature.
* Be fully testable.
* Keep the code clean.
* Preserve existing functionality.
* Follow the design system.
* End with a Git commit.

GameGear is not intended to be an Amazon clone.
